# DynamicXPDays 1.2.1

A lightweight multilingual Paper plugin for configurable XP event days and automatic XP multipliers.

## Features

- Configurable XP multiplier
- Configurable active weekdays
- Europe/Berlin timezone by default
- Automatic player client-language detection
- 21 included languages
- Join notification on active days
- Repeating chat notification with configurable interval
- Reload and status commands
- Bypass permission

## Included languages

German, English, French, Spanish, Italian, Portuguese, Dutch, Polish, Russian,
Ukrainian, Turkish, Czech, Danish, Swedish, Norwegian, Finnish, Hungarian,
Romanian, Japanese, Korean and Chinese.

Unsupported client languages automatically use the configured fallback language.

## Commands

- `/dynamicxpdays status`
- `/dynamicxpdays reload`
- Aliases: `/xpdays`, `/dynamicxp`, `/dxp`, `/doublexp`

## Permissions

- `dynamicxpdays.status`
- `dynamicxpdays.reload`
- `dynamicxpdays.bypass`
